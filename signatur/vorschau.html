Einrichten

Der Kopieren-Button legt die formatierte Signatur in die Zwischenablage — einfach einfügen.

  1. Gmail: Einstellungen → Alle Einstellungen anzeigen → Allgemein → Signatur → Neu erstellen → einfügen mit Strg/Cmd + V.
  2. Outlook (Web): Einstellungen → E-Mail → Verfassen und antworten → Signatur → einfügen.
  3. Outlook (Desktop): Datei → Optionen → E-Mail → Signaturen → Neu → einfügen. Falls die Farben verloren gehen, stattdessen werkanio-signatur.html im Browser öffnen, dort markieren und kopieren.
  4. Apple Mail: Einstellungen → Signaturen → neue Signatur anlegen, „Standardschrift immer verwenden" deaktivieren, dann einfügen.

Vor dem ersten Versand

Name und Fließtext haben keine feste Textfarbe — die übernimmt das Mail-Programm. So bleibt die Signatur auf weißem wie auf dunklem Hintergrund lesbar.

Die Pflichtangaben sind für ein Einzelunternehmen ausgelegt: Name, Anschrift und USt-IdNr. genügen (§ 5 TMG). Sobald Werkanio als GmbH oder UG firmiert, kommen Registergericht, HRB-Nummer und Geschäftsführer dazu (§ 35a GmbHG).
